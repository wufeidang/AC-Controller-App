# 02-架构知识图谱

## 分层架构总览

项目采用**分层架构 + Mixin 复用**模式，共 8 层：

| 层级 | 目录 | 文件数 | 职责 |
|------|------|--------|------|
| 入口层 | 根目录 | 4 | 应用启动与全局配置 |
| 配置层 | config/ | 1 | 全局常量与映射表 |
| 服务层 | services/ | 2 | 设备通信与错误处理 |
| 复用层 | mixins/ | 2 | 跨页面逻辑复用 |
| 组件层 | components/ | 5 | 可复用 UI 组件 |
| 页面层 | pages/ | 16 | 用户交互页面 |
| 原生模块层 | uni_modules/ | 1 | uni-app 原生能力扩展 |
| 资源层 | static/ | 51+ | 静态资源与图标 |

---

## 各层节点详情

### 入口层

| 文件 | 职责 |
|------|------|
| `main.js` | 应用入口，兼容 Vue 2/3 双模式启动 |
| `App.vue` | 全局应用组件，提供全局错误提示 Toast |
| `manifest.json` | uni-app 应用配置清单，定义平台能力与打包参数 |
| `pages.json` | 页面路由配置，定义 16 个页面路径与导航栏样式 |

### 配置层

| 文件 | 内容 |
|------|------|
| `config/constants.js` | HTTP_TIMEOUT(8000ms)、POLL_INTERVAL(10000ms)、DEFAULT_IP(192.168.4.1)、OTA_TIMEOUT(60000ms)、BRAND_MAP(15 品牌)、MODE_LABELS、FAN_LABELS、SWING_LABELS、ERROR_MESSAGES、SCENES、EEPROM_FLUSH_INTERVAL |

### 服务层

| 文件 | 职责 |
|------|------|
| `services/api.js` | 设备通信核心，封装 HTTP POST 请求到 ESP8266 :80 端口。28 个 API 方法，连续失败 3 次判定离线 |
| `services/errorHandler.js` | 错误处理工具类，提供统一的 Toast 提示（handleError/handleSuccess/showLoading/hideLoading） |

### 复用层

| 文件 | 职责 |
|------|------|
| `mixins/device-mixin.js` | 设备状态 mixin，抽取 checkDevice() 方法供页面复用 |
| `mixins/modal-mixin.js` | 弹窗 mixin，抽取 showToast/showConfirm 方法供页面复用 |

### 组件层

| 文件 | 职责 |
|------|------|
| `components/Button.vue` | 基础按钮组件，支持 primary/secondary/danger 三种类型 |
| `components/Card.vue` | 卡片容器组件，支持标题、图标、自定义类名 |
| `components/CustomModal.vue` | 自定义弹窗组件，支持 success/error/warning/info 四种类型 |
| `components/Loading.vue` | 全局加载遮罩组件，显示旋转 spinner + 文本 |
| `components/SettingItem.vue` | 设置项组件，支持图标、值显示、危险操作样式 |

### 页面层

#### 核心页面

| 文件 | 职责 |
|------|------|
| `pages/index/index.vue` | 首页/控制面板，温湿度 Hero 卡片、空调开关、场景快捷条 |
| `pages/device/device.vue` | 设备连接页，WiFi 扫描 + mDNS 设备发现 + 手动 IP/域名输入 |
| `pages/settings/settings.vue` | 设置中心页，分类展示所有设置入口 |

### 原生模块层

| 文件 | 职责 |

## 数据流

### 设备通信

```
页面操作 → apiService.setDeviceAddress() → HTTP POST → ESP8266 :80
           ← JSON 响应 → 页面更新 UI
```

### 状态持久化

```
连接成功 → uni.setStorageSync('connectedDevice', { ip, id })
页面加载 → uni.getStorageSync('connectedDevice') → apiService.setDeviceAddress()
```

### 事件总线

```
pages/device/device.vue → uni.$emit('deviceConnected', data)
pages/index/index.vue → uni.$on('deviceConnected', handler)
```
