# 01-项目概览

## 项目简介

**空调温控 App** 是一个基于 ESP8266 的空调智能控制系统移动端应用。通过 HTTP POST 与 ESP8266 设备通信，实现对空调的远程控制、温湿度监测、场景切换、OTA 升级等功能。

## 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | uni-app (HBuilderX) |
| 前端 | Vue 3.0（兼容 Vue 3 双模式启动） |
| 布局 | 原生 rpx 响应式布局 |
| 状态管理 | uni.getStorageSync + uni.$emit/uni.$on 事件总线 |
| 通信 | HTTP POST → ESP8266 :80 端口 |
| WiFi | uni_modules/uni-wifi（UTS 跨平台） |
| 目标平台 | Android App / H5 / 微信小程序 |

## 核心数据流

```
用户操作 → 页面 .vue → mixin (checkDevice) → apiService (HTTP POST)
                                                ↓
                                         ESP8266 :80 端口
                                                ↓
                                         JSON 响应 → 页面更新 UI
```

- **轮询机制**: 首页每 10 秒轮询设备状态
- **离线检测**: apiService 连续失败 3 次判定离线
- **设备连接**: WiFi 扫描 + mDNS 自动发现 + 手动 IP/域名输入

## 关键特性

- **双模式 WiFi**: AP + STA 共存，本地管理 + 互联网访问
- **MQTT 集成**: 支持 Home Assistant 自动发现
- **15 个空调品牌**: TCL/美的/海尔/格力/大金/三菱/松下/三星/LG/东芝/日立/富士通/夏普/开利/惠而浦
- **4 个场景模式**: 睡眠/舒适/节能/快速
- **EEPROM 保护**: 脏标记延迟写入，保护闪存寿命
- **OTA 升级**: 远程固件更新
