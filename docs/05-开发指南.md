## 构建命令

### HBuilderX（推荐）

1. 使用 HBuilderX 打开项目
2. 运行 → 运行到手机或模拟器
3. 发行 → 原生 App-云打包 / 本地打包

### CLI 方式

```bash
# 安装依赖
npm install

# 运行到浏览器
npm run dev:h5

# 构建 H5
npm run build:h5

# 构建 Android App
npm run build:app-android
```

| 类型 | 说明 | 示例 |

## 调试技巧

### WiFi 权限（Android）

设备连接页需要 WiFi 扫描权限，Android 6.0+ 需要动态申请位置权限：

```javascript
// device.vue 中已实现
plus.android.requestPermissions(
  ['android.permission.ACCESS_FINE_LOCATION', 'android.permission.ACCESS_WIFI_STATE'],
  (result) => { /* 权限获取成功 */ }
);
```

### 设备连接

1. **mDNS 自动发现**: 点击「扫描」按钮，App 自动探测局域网内的 ESP8266 设备（域名 `esp8266-ac.local`），无需手动输入 IP
2. **AP 模式**: 手机连接 ESP8266 热点（默认 SSID: ESP8266-AC），IP 固定为 `192.168.4.1`
3. **STA 模式**: 设备连接家庭 WiFi 后，通过 `get_sta_wifi` 获取动态 IP
4. **双模式**: AP + STA 共存，AP 用于本地管理，STA 用于互联网访问

> **mDNS 兼容性**: iOS/macOS 原生支持 Bonjour，Android 12+ 系统级支持 mDNS 解析。Android 11 及以下需通过 IP 回退策略连接。

### 调试 API

使用 `curl` 或 Postman 直接测试设备 API：

```bash
curl -X POST http://192.168.4.1/ \
  -H "Content-Type: application/json" \
  -d '{"cmd":"get_status"}'
```

### 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 连接超时 | 设备未通电 / IP 错误 | 检查设备状态，确认 IP |
| WiFi 扫描为空 | 缺少位置权限 | 授予位置权限后重试 |
| 空调不响应 | 品牌不匹配 | 尝试切换品牌（美的/格力/TCL） |
| 数据丢失 | 切后台清空 storage | 已修复（宪法原则 I） |

## 开发约束

- **语言**: JavaScript (Vue2) — 不加 TypeScript
- **状态管理**: 优先抽取 mixin，不引入 Vuex/Pinia
- **UI 风格**: Ant Design 蓝 #1677FF + 圆角卡片
- **兼容性**: uni-app HBuilderX 构建，支持 Android/iOS/H5
