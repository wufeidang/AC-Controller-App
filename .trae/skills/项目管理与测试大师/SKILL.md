# 项目管理与测试大师

## 描述

此技能为空调温控项目提供专业的项目管理和测试支持，包括项目规划、代码管理、测试策略和质量保证等核心功能。针对ESP8266和uni-app混合开发项目的特殊需求，提供符合软件工程规范的解决方案。

## 使用场景

- 规划项目开发流程
- 管理代码版本和发布
- 制定测试策略和用例
- 确保代码质量和稳定性
- 处理项目问题和优化

## 项目架构

### 前端架构
- **框架**: uni-app
- **语言**: Vue.js
- **页面结构**: 
  - pages/index - 主页面
  - pages/settings - 设置页面
  - components - 公共组件
  - services - API服务
- **状态管理**: 本地存储 + API数据

### 后端架构
- **硬件**: ESP8266
- **框架**: Arduino Core
- **通信**: HTTP + JSON
- **存储**: SPIFFS + EEPROM

### 通信协议
- **协议**: HTTP POST
- **数据格式**: JSON
- **端口**: 80
- **认证**: 基础认证（可选）

## 代码管理规范

### Git分支策略
- **main**: 主分支，用于生产环境
- **develop**: 开发分支，用于集成新功能
- **feature/*** : 功能分支，用于开发新功能
- **bugfix/*** : 修复分支，用于修复bug
- **hotfix/*** : 紧急修复分支，用于生产环境修复

### 提交规范
- **格式**: `type(scope): subject`
- **类型**: feat, fix, docs, style, refactor, test, chore
- **示例**: `feat(api): add temperature calibration endpoint`

### 代码审查
- 至少一人审查
- 检查代码质量和规范
- 验证功能正确性
- 确保测试覆盖率

## 测试策略

### 单元测试
- **前端**: 组件测试、工具函数测试
- **后端**: 传感器测试、API接口测试
- **覆盖率**: 目标80%以上
- **工具**: Jest, Mocha, Unity

### 集成测试
- **前后端通信**: API请求和响应
- **硬件集成**: 传感器和红外控制
- **场景测试**: 完整的用户操作流程
- **工具**: Postman, 硬件测试台

### 端到端测试
- **用户流程**: 从连接到控制的完整流程
- **异常场景**: 网络中断、设备重启等
- **性能测试**: 响应时间、并发请求
- **工具**: Cypress, Selenium, 真机测试

### 性能测试
- **响应时间**: API响应 < 500ms
- **内存使用**: ESP8266内存使用 < 80%
- **并发处理**: 支持多个客户端连接
- **稳定性**: 连续运行24小时无崩溃
