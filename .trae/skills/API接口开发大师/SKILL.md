# API接口开发大师

## 描述

此技能为ESP8266空调控制器提供专业的API接口开发支持，包括接口设计、数据格式定义、错误处理和文档生成等核心功能。针对RESTful API和JSON通信的特殊需求，提供符合API设计规范的解决方案。

## 接口设计规范

### 请求格式
```json
{
  "cmd": "命令名称",
  "data": {
    "参数1": "值1",
    "参数2": "值2"
  }
}
```

### 响应格式
```json
{
  "status": "success|error",
  "data": {
    "返回数据"
  }
}
```

### 错误响应格式
```json
{
  "status": "error",
  "data": {
    "message": "错误信息"
  }
}
```

## 接口列表

### 设备管理
- `get_status` - 获取设备状态
- `get_device_info` - 获取设备信息
- `get_system_info` - 获取系统信息
- `restart_device` - 重启设备
- `factory_reset` - 恢复出厂设置
- `enter_deep_sleep` - 进入深度睡眠

### 温湿度控制
- `get_temp_hum` - 获取温湿度数据
- `get_temp_hum_threshold` - 获取温湿度阈值
- `set_temp_hum` - 设置温湿度阈值
- `get_calibration` - 获取校准参数
- `set_calibration` - 设置校准参数

### 空调控制
- `get_ac_params` - 获取空调参数
- `set_ac_params` - 设置空调参数
- `set_ac_brand` - 设置空调品牌
- `control_ac` - 控制空调开关

### 场景模式
- `get_scene` - 获取场景模式
- `set_scene` - 设置场景模式

### 定时任务
- `get_timer` - 获取定时任务
- `set_timer` - 设置定时任务
- `delete_timer` - 删除定时任务

### 设备配置
- `set_device_info` - 设置设备信息
- `set_ssid` - 设置WiFi SSID
- `set_wifi_password` - 设置WiFi密码

### 固件升级
- `ota_update` - OTA升级

## 数据类型定义

### 温度数据
- **类型**: float
- **范围**: -40.0 ~ 80.0
- **单位**: °C
- **精度**: 0.1

### 湿度数据
- **类型**: float
- **范围**: 0.0 ~ 100.0
- **单位**: %
- **精度**: 1.0

### 空调模式
- **类型**: string
- **可选值**: auto, cool, heat, fan, dry
- **默认值**: cool

### 风速设置
- **类型**: string
- **可选值**: auto, low, medium, high, quiet
- **默认值**: medium

### 风向设置
- **类型**: string
- **可选值**: auto, fixed
- **默认值**: auto

### 空调品牌
- **类型**: string
- **可选值**: tcl, midea
- **默认值**: tcl

## 错误代码定义

### 通用错误
- `Invalid JSON format` - JSON格式无效
- `No data received` - 未接收到数据
- `Unknown command` - 未知命令

### 参数错误
- `Missing required parameters` - 缺少必要参数
- `Invalid parameter value` - 参数值无效
- `Parameter out of range` - 参数超出范围

### 设备错误
- `Sensor read failed` - 传感器读取失败
- `IR send failed` - 红外发送失败
- `WiFi connection lost` - WiFi连接丢失

### 业务错误
- `Invalid AC brand` - 无效的空调品牌
- `No SSID specified` - 未指定SSID
- `No password specified` - 未指定密码
- `Timer limit reached` - 定时任务数量已达上限
- `Timer not found` - 定时任务不存在
- `Invalid scene mode` - 无效的场景模式
