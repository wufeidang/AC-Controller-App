# 空调温控前端UI设计大师

## 描述

此技能为空调温控项目提供专业的前端UI设计能力，包括界面设计、组件开发、交互优化和跨平台适配等核心功能。针对温控应用的特殊需求，提供符合智能家居应用设计规范的解决方案。

## 使用场景

- 设计温控应用的界面风格和布局

## 设计规范

### 色彩方案
- **主色调**: #007aff (蓝色) - 表示科技感和专业性
- **成功色**: #52c41a (绿色) - 表示正常运行
- **警告色**: #faad14 (橙色) - 表示需要注意
- **错误色**: #ff4d4f (红色) - 表示异常或高温
- **温度色**: #ff7a45 (橙色) - 用于温度相关元素
- **湿度色**: #1890ff (蓝色) - 用于湿度相关元素

### 字体规范
- **标题**: 40rpx, font-weight: 700
- **副标题**: 26rpx, font-weight: 400
- **正文**: 28rpx, font-weight: 600
- **辅助文字**: 24rpx, font-weight: 400
- **小字**: 22rpx, font-weight: 500

### 间距规范
- **页面边距**: 30rpx
- **卡片内边距**: 30rpx
- **元素间距**: 20rpx
- **小组件间距**: 12rpx

### 圆角规范
- **卡片圆角**: 16rpx
- **按钮圆角**: 12rpx
- **小组件圆角**: 8rpx
- **圆形元素**: 50%

### 阴影规范
- **轻微阴影**: 0 2rpx 8rpx rgba(0, 0, 0, 0.05)
- **中等阴影**: 0 4rpx 16rpx rgba(0, 0, 0, 0.1)
- **强调阴影**: 0 4rpx 16rpx rgba(0, 122, 255, 0.15)

## 组件设计原则

### 1. 卡片组件
- 使用白色背景，圆角16rpx
- 添加轻微阴影增加层次感
- 支持悬停和点击效果
- 提供选中状态的视觉反馈

### 2. 状态指示器
- 使用颜色区分不同状态
- 提供清晰的文字说明
- 添加动画效果增强反馈
- 确保在各种背景下都清晰可见

### 3. 数据展示
- 使用进度条或图表展示数值
- 根据数值范围显示不同颜色
- 提供单位标识和标签
- 确保数值变化的平滑过渡

### 4. 交互元素
- 按钮有明确的悬停和点击效果
- 提供触摸反馈
- 动画时长控制在0.3s以内
- 确保可访问性和易用性

## 性能优化建议
