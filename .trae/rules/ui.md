# UniApp 项目 UI 设计规则
## 1. 设计原则
### 1.1 核心原则
- 一致性 ：保持视觉元素和交互模式的一致性
- 简洁性 ：减少视觉噪音，突出核心功能
- 易用性 ：直观的操作流程，减少学习成本
- 响应式 ：适配不同尺寸的设备屏幕
- 性能优先 ：优化动画和交互，确保流畅体验
### 1.2 设计理念
- 原生体验 ：参考各平台原生应用的设计风格
- 跨平台统一 ：在不同平台保持一致的用户体验
- 品牌一致性 ：确保设计符合品牌视觉识别系统
## 2. 色彩系统
### 2.1 主色
- 主色调 ： #007AFF （iOS蓝）- 用于主要按钮、链接和强调元素
- 辅助色 ：
  - 成功： #52C41A
  - 警告： #FAAD14
  - 错误： #FF4D4F
  - 信息： #1890FF
### 2.2 中性色
- 背景色 ： #F5F5F5
- 卡片背景 ： #FFFFFF
- 文本色 ：
  - 主文本： #333333
  - 次要文本： #666666
  - 辅助文本： #999999
- 边框色 ： #E8E8E8
### 2.3 色彩使用规范
- 主色用于关键操作和品牌识别
- 辅助色用于状态反馈和提示
- 中性色用于背景、文本和边框
- 确保文本与背景的对比度符合可访问性标准
## 3. 字体系统
### 3.1 字体选择
- 默认字体 ：使用系统默认字体，确保跨平台一致性
- 字体家族 ：
  - iOS: San Francisco
  - Android: Roboto
  - Web: 系统默认字体
### 3.2 字号规范
- 大标题 ：20-24px
- 中标题 ：18-20px
- 小标题 ：16-18px
- 正文 ：14-16px
- 辅助文本 ：12-14px
- 提示文本 ：10-12px
### 3.3 字重规范
- 粗体 ：600-700 - 用于标题和强调
- 常规 ：400-500 - 用于正文
- 细体 ：300-400 - 用于辅助文本
## 4. 布局规范
### 4.1 间距系统
- 基础间距 ：4px
- 常用间距 ：
  - 小间距：8px
  - 中间距：16px
  - 大间距：24px
  - 特大间距：32px
### 4.2 网格系统
- 栅格 ：12列网格系统
- 列间距 ：16px
- 边距 ：16px（左右）
### 4.3 响应式设计
- 断点 ：
  - 小屏幕：< 750px
  - 中等屏幕：750px - 1024px
  - 大屏幕：> 1024px
- 布局策略 ：
  - 小屏幕：单列布局
  - 中等屏幕：双列布局
  - 大屏幕：多列布局
### 4.4 安全区域
- iOS 安全区域 ：适配刘海屏和底部安全区域
- Android 导航栏 ：适配底部导航栏高度
## 5. 组件规范
### 5.1 按钮
- 类型 ：
  - 主要按钮：填充主色，白色文本
  - 次要按钮：白色背景，主色边框
  - 文本按钮：无背景，主色文本
- 尺寸 ：
  - 大按钮：48px 高度
  - 中按钮：40px 高度
  - 小按钮：32px 高度
- 圆角 ：8-12px
- 状态 ：
  - 正常：标准样式
  - 悬停：轻微变暗
  - 按下：明显变暗
  - 禁用：透明度降低
### 5.2 输入框
- 高度 ：40-48px
- 边框 ：1px 边框，聚焦时主色边框
- 圆角 ：8px
- 内边距 ：12-16px
- 状态 ：
  - 正常：灰色边框
  - 聚焦：主色边框
  - 错误：错误色边框
  - 禁用：灰色背景，禁用状态
### 5.3 卡片
- 背景 ：白色
- 圆角 ：12-16px
- 阴影 ：轻微阴影，增强层次感
- 内边距 ：16-24px
- 边框 ：可选，1px 边框
### 5.4 列表
- 行高 ：48-56px
- 内边距 ：16px
- 分割线 ：1px 边框，颜色为 #E8E8E8
- 点击效果 ：轻微背景变化
### 5.5 弹窗
- 背景 ：白色
- 圆角 ：16px
- 阴影 ：明显阴影
- 内边距 ：24px
- 按钮区域 ：底部按钮对齐，间距16px
## 6. 图标系统
### 6.1 图标风格
- 风格 ：线性图标，简洁现代
- 线条宽度 ：2px
- 圆角 ：4px
- 尺寸 ：
  - 小图标：20px
  - 中图标：24px
  - 大图标：32px
### 6.2 图标使用规范
- 一致性 ：使用同一风格的图标
- 语义化 ：图标应与功能含义匹配
- 位置 ：图标应放置在视觉焦点位置
- 颜色 ：
  - 主要图标：主色
  - 次要图标：中性色
  - 状态图标：对应状态颜色
## 7. 动效设计
### 7.1 过渡动画
- 时间 ：200-300ms
- 曲线 ：ease-in-out
- 类型 ：
  - 淡入淡出：用于模态框和页面切换
  - 滑动：用于列表和抽屉
  - 缩放：用于按钮和卡片
### 7.2 交互反馈
- 点击反馈 ：轻微的按下效果
- 加载反馈 ：骨架屏或加载动画
- 成功/失败反馈 ：Toast 提示
- 拖拽反馈 ：实时视觉反馈
### 7.3 性能优化
- 减少动画复杂度 ：避免过度动画
- 使用硬件加速 ：利用 CSS 硬件加速
- 按需加载 ：仅在必要时使用动画
## 8. 适配规范
### 8.1 屏幕尺寸适配
- 单位 ：使用 rpx 单位，自动适配不同屏幕
- 布局 ：使用 flexbox 和 grid 布局
- 图片 ：使用响应式图片
### 8.2 平台适配
- iOS ：遵循 iOS 设计规范
- Android ：遵循 Material Design 规范
- Web ：遵循 Web 设计最佳实践
### 8.3 暗黑模式
- 支持 ：适配系统暗黑模式
- 颜色 ：调整为适合暗黑环境的颜色方案
- 对比度 ：确保文本与背景的对比度
## 9. 代码规范
### 9.1 组件命名
- 组件名 ：大驼峰命名法，如 BaseButton
- 文件名 ：与组件名一致，如 BaseButton.vue
- Props ：小驼峰命名法，如 buttonType
- 事件 ：短横线分隔，如 @click-event
### 9.2 文件结构
```
components/
  base/           # 基础组件
  layout/         # 布局组件
  business/       # 业务组件
pages/
  page-name/      # 页面文件夹
    index.vue     # 页面文件
    components/   # 页面级组件
static/
  icons/          # 图标
  images/         # 图片
styles/
  variables.scss  # 变量
  global.scss     # 全局样式
```
### 9.3 样式规范
- 使用 SCSS ：利用 SCSS 的变量和嵌套功能
- BEM 命名 ：使用 BEM 命名规范
- 避免 !important ：尽量避免使用 !important
- 复用样式 ：提取公共样式到变量和 mixin
## 10. 最佳实践
### 10.1 首页设计
- 信息层次 ：清晰的信息层级
- 核心功能 ：突出核心功能入口
- 加载状态 ：骨架屏或渐进式加载
- 个性化 ：根据用户偏好定制内容
### 10.2 表单设计
- 分步表单 ：复杂表单拆分为多步
- 实时验证 ：输入时进行验证
- 错误提示 ：明确的错误信息
- 提交反馈 ：加载状态和成功提示
### 10.3 列表设计
- 分组 ：相关项目分组显示
- 排序 ：支持多种排序方式
- 筛选 ：提供筛选功能
- 加载 ：下拉刷新和上拉加载
### 10.4 详情页设计
- 信息架构 ：逻辑清晰的信息组织
- 操作便捷 ：关键操作易于访问
- 相关推荐 ：智能推荐相关内容
- 分享功能 ：方便用户分享
## 11. 设计资源
### 11.1 设计工具
- Figma ：推荐使用 Figma 进行设计
- Sketch ：适用于 macOS 用户
- Adobe XD ：全平台支持
### 11.2 资源库
- 图标库 ：使用 Material Icons 或 Iconfont
- 组件库 ：使用 UniApp 官方组件库或第三方组件库
- 字体 ：使用系统默认字体或 Google Fonts
### 11.3 设计系统
- 建立设计系统 ：创建包含所有组件和样式的设计系统
- 版本控制 ：使用版本控制系统管理设计文件
- 文档 ：维护详细的设计文档
## 12. 测试与优化
### 12.1 测试方法
- 设备测试 ：在不同设备上测试
- 用户测试 ：收集用户反馈
- 性能测试 ：测试加载速度和动画流畅度
### 12.2 优化策略
- 图片优化 ：压缩图片，使用适当格式
- 代码优化 ：减少冗余代码
- 缓存策略 ：合理使用缓存
- 懒加载 ：延迟加载非关键资源
### 12.3 迭代改进
- 数据分析 ：分析用户行为数据
- A/B 测试 ：测试不同设计方案
- 持续改进 ：根据反馈不断优化
